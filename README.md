# 車いすユーザーの駐車環境 調査候補MAP｜東広島市

円陣2026の活動で、東広島市内の「思いやり駐車場利用証交付制度」協力施設をもとに、  
**現地調査の候補を探す・位置を確認する・チームで気づきを残す**ために作成している試作MAPです。

現在の版は、チーム内で実際に触りながら使い方を確かめるための**位置修正可能版／チーム入力機能付き試作版**です。

> [!IMPORTANT]
> 追加した地点、コメント、位置修正、入力履歴などは、**操作した各自のブラウザ内に保存されます。**  
> 同じGitHub PagesのURLを共有した場合も、それぞれのブラウザが独立した作業場所になります。  
> チームで内容を受け渡す場合は、MAP上の **「作業データを出力」→「作業データを読込」** を使用できます。

---

## このMAPでできること

- 東広島市内の登録施設107件を地図上で確認
- 地域、施設種別、車いす等区画、プラスワン区画などで絞り込み
- 候補施設を保存して比較
- Googleマップ／ストリートビューで位置を確認
- 表示位置がずれている施設の座標を修正
- 位置確認状態を記録
  - 未確認
  - 位置確認済み
  - 座標修正済み
  - 要現地確認
- チームで確認したい施設・駐車場などを任意に追加
- 既存施設・追加地点へコメントを記録
- 地点追加、コメント、位置修正などの入力履歴を確認
- 作業データをJSONで出力／読込し、他の端末やメンバーへ受け渡し

---

## 位置情報について

このMAPの表示位置は、**現地調査候補へ到達し、周辺状況を確認するための代表位置**です。

施設所在地と駐車場が離れている場合などは、必要に応じてMAP上の表示位置を修正できます。  
位置修正はMAP上の表示座標に対して行い、広島県が公開している施設名・住所・登録区画数は元データとして保持します。

**「位置確認済み」「座標修正済み」**は、候補地へ到達し周辺状況を確認するための机上確認の状態です。  
現地確認は、駐車区画の実際の位置、幅・奥行、乗降余地、入口までの経路、段差、利用条件などを確かめる別の確認段階として扱います。

---

## チーム追加地点・コメント・履歴について

公開データ由来の107施設とは別の**チーム入力レイヤー**に、任意の地点を追加できます。

たとえば、次のような使い方を想定しています。

- 施設本体とは離れた駐車場を別地点として記録する
- 現地調査で確認したい場所を追加する
- 航空写真やストリートビューを見て気づいた点をコメントする
- 「入口側を確認したい」「乗降スペースを現地確認したい」などの調査メモを残す

地点追加、編集、コメント、位置確認状態の変更、座標修正などは、日時・入力者名とともに履歴へ記録されます。

入力者名は、履歴上で入力者を見分けるための自己申告名として扱います。本人性の確認を伴う運用には、別途認証方法が必要です。

### 試作機能の位置づけ

地点追加、コメント、入力履歴などは、チーム内で使い方を確かめるための試作機能です。  
継続・変更・統合などを含む今後の扱いは、利用状況や運用方法を踏まえてチームで検討する想定です。

## データの保存とチーム共有

### 各ブラウザを作業場所として使います

入力した内容は、使用しているブラウザのローカル保存領域（localStorage）に保存されます。

そのため、同じGitHub PagesのURLを共有しても、各メンバーはそれぞれ独立した作業データを持つ形になります。

### 他のメンバーへ受け渡す場合

MAP上部の

**「作業データを出力」**

からJSONファイルを書き出し、共有相手が

**「作業データを読込」**

を使用することで、作業内容を受け渡せます。

作業データには、位置確認、座標修正、チーム追加地点、コメント、入力履歴などが含まれます。

現段階では、GitHub Pagesを**MAP本体の共有場所**として使い、チーム入力内容の共有はJSONの出力／読込で行う構成です。

ブラウザの保存データを整理・削除する場合は、必要に応じて先に作業データを書き出しておくと引継ぎやすくなります。

## 基本的な使い方

1. 左側の条件で候補施設を絞り込みます。
2. 地図または施設一覧から施設を選択します。
3. 必要に応じてGoogleマップ／ストリートビューで場所を確認します。
4. 表示位置にずれがある場合は座標を修正します。
5. 現地調査候補は「保存」で比較対象に追加します。
6. 新たに気づいた施設・駐車場は「＋ 地点を追加」から登録できます。
7. 気づきや確認事項はコメントとして残せます。
8. 他のメンバーへ作業内容を渡す場合は、作業データをJSONで出力します。

MAP内の `i` 表示や「この地図について」から、各機能の意味や注意事項を確認できます。

## 掲載データ

施設・登録区画数は、広島県「思いやり駐車場利用証交付制度」の協力施設一覧  
（2026年7月公表・東広島市掲載分）をもとにしています。

- 掲載施設：107施設
- 車いす等区画：248区画（登録数の合計）
- プラスワン区画：59区画（登録数の合計）

区画数は、公開登録情報に記載された数です。  
現在の空き状況や利用状態は、施設案内・現地情報と組み合わせて確認します。  
「登録数の記載なし」は、公開一覧で区画数を確認できない状態を表します。

背景地図には国土地理院の地理院タイルを使用しています。

## GitHub Pagesで共有する場合

HTMLをリポジトリのトップページとして表示する場合は、ファイル名を

```text
index.html
```

にすると扱いやすくなります。

推奨する最小構成は次のとおりです。

```text
/
├─ index.html
└─ README.md
```

GitHub Pagesを有効にすると、概ね次の形式のURLで閲覧できます。

```text
https://<GitHubユーザー名>.github.io/<リポジトリ名>/
```

GitHub PagesはMAP本体の共有場所として使えます。  
地点追加・コメント・履歴などの入力内容は各自のブラウザに保存し、チーム共有は作業データの出力／読込で行う構成です。

## 現在の位置づけ

この版は、完成済みの公開Viewerというより、**チームで位置確認・調査方法・入力機能を試すための作業版**として位置づけています。

- 位置修正機能を閉じた閲覧版を用意する

- チーム入力機能の継続・変更・統合を検討する

どの形を採るかは、実際の利用状況やチーム内での検討を踏まえて判断する想定です。

## 利用時の確認事項

このMAPは、公開情報から候補を整理し、現地確認につなげるための試作ツールです。

表示される施設・位置・区画数を候補探索の入口として使い、実際の駐車環境、空き状況、利用条件は施設案内や現地情報と組み合わせて確認します。
