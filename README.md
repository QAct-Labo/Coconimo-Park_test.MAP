# 車いすユーザーの駐車環境 調査候補MAP｜東広島市

円陣2026の活動で、東広島市内の「思いやり駐車場利用証交付制度」協力施設をもとに、  
**現地調査の候補を探す・位置を確認する・チームで気づきを残す**ために作成している試作MAPです。

現在の版は、チーム内で実際に触りながら検証するための**位置修正可能版／チーム入力機能付き試作版**です。

> [!IMPORTANT]
> 追加した地点、コメント、位置修正、入力履歴などは、**操作した各自のブラウザ内に保存されます。**  
> 同じGitHub PagesのURLを他のメンバーが開いても、入力内容が自動的に共有・同期されるわけではありません。  
> 他のメンバーへ渡す場合は、MAP上の **「作業データを出力」→「作業データを読込」** を使用してください。

---

## このMAPでできること

- 東広島市内の登録施設107件を地図上で確認
- 地域、施設種別、車いす等区画、プラスワン区画などで絞り込み
- 候補施設を保存して比較
- Googleマップ／ストリートビューで位置を確認
- 表示位置がずれている施設の座標を修正
- 位置確認状態を記録
  - 未確認
  - 位置確認済み
  - 座標修正済み
  - 要現地確認
- チームで確認したい施設・駐車場などを任意に追加
- 既存施設・追加地点へコメントを記録
- 地点追加、コメント、位置修正などの入力履歴を確認
- 作業データをJSONで出力／読込し、他の端末やメンバーへ受け渡し

---

## 位置情報について

このMAPの表示位置は、**現地調査候補へ到達しやすくするための代表位置**です。

施設所在地と駐車場が離れている場合などは、必要に応じて表示位置を修正できます。  
位置修正は、このMAP上の表示座標を修正するものであり、広島県が公開している元データの施設名・住所・登録区画数を書き換えるものではありません。

また、

**「位置確認済み」「座標修正済み」＝「現地確認済み」ではありません。**

駐車区画そのものの位置、幅・奥行、乗降余地、入口までの経路、段差、利用条件などは、必要に応じて現地で確認します。

---

## チーム追加地点・コメント・履歴について

公開データ由来の107施設とは別に、チームメンバーが任意の地点を追加できます。

追加地点は、たとえば次のような使い方を想定しています。

- 施設本体とは離れた駐車場を別地点として記録する
- 現地調査で確認したい場所を追加する
- 航空写真やストリートビューを見て気づいた点をコメントする
- 「入口側を確認したい」「乗降スペースを現地確認したい」などの調査メモを残す

入力時に設定した表示名と日時が履歴に残ります。

表示名は**履歴を見やすくするための自己申告名**であり、本人認証を行う仕組みではありません。

### 試作機能です

地点追加、コメント、入力履歴などは、チームでの調査・検討方法を試すための機能です。  
今後の利用状況や運用方法に応じて、**変更・統合・終了する可能性があります。**

## データの保存とチーム共有

### ブラウザ内保存

入力した内容はブラウザのローカル保存領域（localStorage）に保存されます。

そのため、

- 同じURLでも、別の人のブラウザには自動反映されません
- 別のPC・ブラウザでは同じ入力内容が自動では表示されません
- ブラウザの保存データを削除すると、入力内容が失われる可能性があります

### 他のメンバーへ渡す場合

MAP上部の

**「作業データを出力」**

からJSONファイルを書き出し、共有相手が

**「作業データを読込」**

を使用してください。

作業データには、位置確認、座標修正、チーム追加地点、コメント、入力履歴などが含まれます。

現段階では、GitHubは**MAP本体を共有する場所**であり、チーム入力内容をリアルタイム同期するサーバーではありません。

## 基本的な使い方

1. 左側の条件で候補施設を絞り込みます。
2. 地図または施設一覧から施設を選択します。
3. 必要に応じてGoogleマップ／ストリートビューで場所を確認します。
4. 表示位置にずれがある場合は座標を修正します。
5. 現地調査候補は「保存」で比較対象に追加します。
6. 新たに気づいた施設・駐車場は「＋ 地点を追加」から登録できます。
7. 気づきや確認事項はコメントとして残せます。
8. 他のメンバーへ作業内容を渡す場合は、作業データをJSONで出力します。

MAP内の `i` 表示や「この地図について」から、各機能の意味や注意事項を確認できます。

## 掲載データ

施設・登録区画数は、広島県「思いやり駐車場利用証交付制度」の協力施設一覧  
（2026年7月公表・東広島市掲載分）をもとにしています。

- 掲載施設：107施設
- 車いす等区画：248区画（登録数の合計）
- プラスワン区画：59区画（登録数の合計）

区画数は公開登録情報上の数であり、現在の空き台数や利用可能な状態を示すものではありません。  
「登録数の記載なし」は「0区画」を意味しません。

背景地図には国土地理院の地理院タイルを使用しています。

## GitHub Pagesで共有する場合

HTMLをリポジトリのトップページとして表示する場合は、ファイル名を

```text
index.html
```

にしておくと扱いやすくなります。

推奨する最小構成は次のとおりです。

```text
/
├─ index.html
└─ README.md
```

GitHub Pagesを有効にすると、概ね次の形式のURLで閲覧できます。

```text
https://<GitHubユーザー名>.github.io/<リポジトリ名>/
```

### 注意

GitHub Pagesで共有しても、チームメンバーがMAPへ入力した内容がGitHubへ書き込まれることはありません。  
入力内容は各自のブラウザに保存されます。

## 現在の位置づけ

この版は、完成済みの公開Viewerではなく、**チームで位置確認・調査方法・入力機能を試すための作業版**です。

今後、位置確認やデータ整理が完了した段階では、

- 位置修正機能を閉じる
- 確定した位置情報を固定する
- 必要な情報だけを閲覧できるViewerへ移行する

といった運用を想定しています。

まずはチーム内で実際に使用し、「何が役立つか」「何が不要か」「どこで迷うか」を確認しながら調整していきます。

## 免責・注意

このMAPは現地調査候補を整理するための試作ツールです。

表示されている施設・位置・区画数だけで、車いすユーザーに適した駐車環境であること、駐車可能であること、現在利用できることを保証するものではありません。  
実際の利用条件や現況は、現地および各施設の案内等で確認してください。
