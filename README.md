# 東広島 駐車環境調査MAP

**円陣2026｜車いすユーザーの駐車環境 調査候補MAP**  
対象バージョン：**v2.1.2（指定座標107施設・ズームアニメーション・候補ポップアップ識別）**  
対応ファイル：`Higashihiroshima_ParkingMAP_v2.1.2.html`

## 1. このMAPの目的

東広島市内の施設を入口として、車いすユーザーの駐車環境について「見に行きたい場所」を選び、地図上で駐車場候補地点を追加し、現地で確かめるための**参加型調査支援ツール**です。

広島県の「思いやり駐車場利用証交付制度」協力施設一覧に掲載された東広島市の107施設を初期対象としています。施設を検索し、車いす等区画やプラスワン区画の情報を比べ、候補地点と調査メモを共有できます。

**このMAPは、全施設の駐車区画・出入口を確定した地図でも、東広島市内に存在するすべての優先駐車区画の網羅一覧でもありません。** 現地で確かめるための出発点として利用してください。

## 2. すぐに使う

1. `Higashihiroshima_ParkingMAP_v2.1.2.html` をダウンロードします。
2. ファイルをブラウザ（Chrome、Edgeなど）で開きます。サーバーの構築やソフトウェアのインストールは不要です。
3. 左側で施設名・住所、地域、施設種別、車いす等区画数、プラスワンを使って絞り込みます。
4. 施設一覧または地図上の施設点を選びます。
5. ポップアップから指定座標をGoogleマップ／ストリートビューで確認したり、「ここに行ってみたい」「駐車場候補を追加」を操作したりします。保存済みの候補点は、ポップアップの色で識別できます。
6. 調査対象を選んだら、共有文のコピーまたはJSON書き出しを利用します。

> **通信について：** HTML内に施設・交通量データと地図操作のプログラムが含まれています。一方、背景地図には国土地理院のオンライン地図タイルを使用し、Googleマップとストリートビューも外部サイトを開きます。これらの表示にはインターネット接続が必要です。

## 3. 収録データ

| データ | 内容 | 扱い |
| --- | --- | --- |
| 施設 | **107施設**（施設IDは全件固有） | Excelの指定座標で表示 |
| 車いす等区画 | 数値記載106施設、合計**248区画** | 施設の属性・検索条件 |
| プラスワン区画 | 数値記載42施設、合計**59区画** | 施設の属性・検索条件 |
| 道路交通センサス | **214道路基本区間**（うち交通量数値あり211区間） | R3参考道路レイヤー |
| 駐車場候補地点 | 利用者が追加した地点 | 施設位置とは別にブラウザ内で保存 |

**「記載なし」は0区画を意味しません。** 元の施設情報に数値がない状態として扱います。また、区画数や施設名称の現況を現地確認済みと保証するものではありません。

### 施設の表示座標

- 施設位置には、提供されたExcelの **`施設監査107 (2)` タブに入力された緯度・経度**を採用しています。
- **107施設すべてに指定座標を設定**しています。以前の住所代表点、町域代表点、過去の位置監査結果を使って施設点を再配置する処理はありません。
- この位置は**利用者が指定した「施設の表示座標」**です。Google Maps等による独立した同定・現地検証を意味せず、車いす区画の中心、乗降場所、施設出入口を直接示すものでもありません。
- 施設IDと指定座標はHTML内に固定して保持します。利用者が追加した駐車場候補地点が施設座標を上書きすることはありません。

### 道路交通センサス

- 出典：**令和3年度（2021年度）全国道路・街路交通情勢調査（一般交通量調査）**。
- 東広島市に関係する214道路基本区間の線形・属性データをHTML内に収録しています。
- 道路を選ぶと、交通量（24時間・昼間12時間）、大型車混入率、混雑度、旅行速度（上り・下り）、車線数、基本区間番号を確認できます。
- 色の区分は**24時間交通量**による4段階（2,500台/日未満、2,500～6,999、7,000～13,499、13,500以上）です。交通量値のない区間も存在します。
- 交通量は**令和3年度時点の道路区間の代表値**です。現在の実測交通量、個別施設の出入口交通量、駐車場内の通行量を表すものではありません。

## 4. 主な操作

### 4-1. 施設を探す・絞り込む

左サイドバーの「施設を探す」で以下を組み合わせて指定できます。

| 項目 | できること |
| --- | --- |
| 施設名・住所 | 部分一致検索。変更前の施設名でも検索可 |
| 地域 | 西条・黒瀬・高屋などの地域で絞り込み |
| 施設種別 | 役所・医療施設・商業施設などで絞り込み |
| 車いす等区画 | 1・2・3・5区画以上を選択 |
| プラスワン | 「登録あり」または「記載なし」を選択 |
| 行ってみたいだけ | 自分が選んだ施設だけ表示 |
| 候補地点ありだけ | 駐車場候補を登録した施設だけ表示 |

「絞り込みを解除」で条件を初期化し、「表示中を地図に収める」で該当施設・候補地点を収めた表示に切り替えられます。

### 4-2. 地図の見え方を変える

- **指定座標107施設を表示**：施設点の表示／非表示を切り替えます。
- **背景地図の濃さ**：上側スライダーで地図タイルの濃さを調整します（初期値72%）。
- **道路交通センサス（R3）**：道路レイヤーの表示／非表示を切り替えます。
- **道路交通センサスの濃さ**：下側スライダーで交通量線形レイヤーの濃さを調整します（初期値55%）。
- **サイドバー文字サイズ**：文字の大きさを地図の縮尺とは独立して調整します。
- **地図移動・拡大縮小**：ドラッグ、マウスホイール、地図の「＋」「－」を使用できます。拡大・縮小時には滑らかなアニメーションが表示されます。

※「指定座標107施設を表示」をオフにしても、施設一覧・検索条件・保存済み候補地点は削除されません。

#### v2.1.2：拡大・縮小アニメーション

- 地図右上の **「＋」「－」**、または**マウスホイール**でズームすると、約**0.32秒（320ミリ秒）**の滑らかな変化を表示します。
- 「＋」「－」ボタンでは画面中央、マウスホイールでは**マウスポインターの位置**を基準に拡大・縮小します。操作前後の位置関係を追いやすくするための仕様です。
- 地図上に開いている**施設・候補のポップアップは保持**し、地点とポップアップを結ぶ線をアニメーションに追従させます。
- 続けてズームした場合や、ズーム中に地図をドラッグした場合は、アニメーションを適切に終了し、新しい操作を優先します。
- OS／ブラウザの「動きを減らす」（`prefers-reduced-motion`）設定が有効な場合、アニメーションは使用せず表示を切り替えます。
- アニメーションは**地図の表示効果**であり、施設座標・候補座標・交通量の数値には影響しません。


### 4-3. 施設のポップアップ

施設点または施設一覧をクリックすると、施設名、登録住所、指定座標、車いす等・プラスワン区画数などを表示します。

主なボタンは次のとおりです。

- **指定座標をGoogleマップで開く**：施設の指定緯度・経度をGoogleマップで表示。
- **ストリートビュー**：指定座標の周辺パノラマ表示へ移動。
- **ここに行ってみたい**：サイドバーの「今回見に行きたい」に登録／解除。
- **駐車場候補を追加**：地図上に新たな調査候補地点を作成。

Googleストリートビューは指定座標から最寄りの閲覧可能なパノラマへ移動することがあり、指定位置の映像とは限りません。

ポップアップは**複数表示**でき、見出しをドラッグして動かせます。対象点との接続線で対応関係を示します。「詳細をすべて閉じる」でまとめて閉じられます。

### 4-4. 駐車場候補を追加・確認する

1. 対象施設を開き、**「駐車場候補を追加」**を押します。
2. 地図上の候補位置をクリックします。
3. 必要に応じてメモを書き、**「この地点を候補にする」**で保存します。
4. 保存した候補点を選ぶと、Googleマップ、ストリートビュー、メモ変更、**「現地確認済みにする」**、削除が利用できます。
5. 確認済みとして記録した候補は、必要に応じて候補状態へ戻せます。

候補地点は1施設に**複数追加**できます。青色の候補点は「現地確認済み」として操作した状態を表し、第三者による確認・品質保証を自動的に付与するものではありません。

#### v2.1.2：保存した候補地点のポップアップの色分け

| 開いているポップアップ | 配色 | 意味 |
| --- | --- | --- |
| 施設情報 | **白** | 最初から収録されている施設の情報 |
| 駐車場候補 | **淡いオレンジ** | 利用者が**意図的に保存した調査候補地点** |
| 現地確認済み候補 | **淡いブルー** | 利用者が「現地確認済み」として記録した候補地点 |

候補点のポップアップには **「意図的に保存した地点」** と表示し、施設の情報と区別します。「現地確認済み」に変更すると色・表示文言が切り替わり、「候補へ戻す」で元の候補色に戻ります。

**色はデータの出所と作業状態の目印です。** 施設情報の正確性、駐車枠の寸法、利用可否、現地確認の客観的な証明を表すものではありません。


### 4-5. 「今回見に行きたい」と共有

- 施設ポップアップの「ここに行ってみたい」で、調査したい施設をリスト化します。
- 選択した施設には、共有用の理由・観察メモを書けます。
- **共有文をコピー**：施設名、住所、区画数、候補地点、メモをまとめたテキストをコピーします。SlackやLINEなどへの貼り付けを想定しています。
- **共有データJSON**：選択施設、メモ、候補地点をファイルへ書き出します。
- **JSONを読込**：他のブラウザやメンバーが出力した共有ファイルを読み込みます。
- **選択を解除**：「今回見に行きたい」の選択と共有メモだけを消去します。登録済み駐車場候補地点は残ります。

> **重要：JSON読込は追加・マージではなく、現在の選択施設・メモ・候補地点を読み込んだ内容へ置き換えます。** 読込前に、現在の情報を「共有データJSON」で保存してください。

## 5. 保存と共有に関する注意

### ブラウザ内での保存

「行ってみたい」、共有メモ、駐車場候補地点、文字サイズ設定は、ブラウザの**LocalStorage（ローカル保存領域）**に保存されます。

- **自動的なクラウド同期やチーム間の共同編集はありません。** 他の人の画面には自動反映されません。
- 別のブラウザ、端末、閲覧URL、プライベートブラウジングでは保存内容を共有できない場合があります。
- ブラウザのサイトデータ削除や保存領域の制限により、ローカル保存内容を失う可能性があります。
- 保存すべき作業結果は定期的に**共有データJSONでバックアップ**してください。
- 旧版を同じブラウザで開いていた場合、保存領域のキーが共通のため、以前の「行ってみたい」や候補地点が読み込まれることがあります。施設の指定座標が旧情報に上書きされることはありません。

### チームでの受け渡し

推奨する運用は、**HTML本体を共通版として配布し、各人の作業結果はJSONファイルで受け渡す**方法です。JSONを取り込む担当者は、既存情報を書き出してから読み込んでください。JSONを複数人で同時編集した結果を自動統合する機能はありません。

### 外部共有への配慮

候補地点のメモには、個人情報、通行人・車両の識別につながる情報、非公開の連絡先などを記入しないでください。共有JSONにはメモと候補地点の座標が含まれます。

## 7. 開発・更新時のデータ管理

HTML内の主なデータ定義は以下です。

| 定数 | 内容 |
| --- | --- |
| `FACILITIES` | 107施設のID・名称・住所・区画数・指定座標など |
| `TRAFFIC_CENSUS` | R3道路区間の属性と道路線形 |
| `TRAFFIC_CENSUS_META` | 交通量抽出元・対象地域・件数・ハッシュなどのメタ情報 |
| `SOURCE` | 施設の元資料に関するメタ情報 |

施設位置の改訂時は**施設IDを突合キー**として座標マスターから再生成し、次の検査を推奨します。

1. 施設数107件、施設ID重複なし、緯度・経度形式の欠損なし。
2. 入力タブの緯度・経度と、`FACILITIES[].point.lat` / `.lon` が全件一致。
3. 名称変更3件の表示と旧名称検索が維持されていること。
4. 車いす等・プラスワンの数値および未記載状態が維持されていること。
5. 地図・交通量のスライダー、検索、ポップアップ、ストリートビュー、候補地点追加、JSONの書出／読込を確認。
6. HTMLのバージョンとREADMEの対応バージョンを同時更新。

ブラウザ内の作業データは固定施設マスターと別管理です。**施設表示点と駐車場候補地点を同一の座標項目に統合しない**ことを基本原則とします。

## 8. 現時点での制約

- 107施設の指定座標は利用者指定値であり、個々の駐車区画・入口の実測位置とは限りません。
- 公開施設一覧が収録していないファミリーレストラン等の未登録・登録状況不明施設は、自動的には追加されません。
- 優先区画の寸法、乗降余地、路面、段差、入口までの動線、常時利用可能かなどは**現地確認が必要**です。
- R3交通量は2021年度の道路区間代表値であり、リアルタイム情報ではありません。
- 「現地確認済み」は利用者が付ける状態です。確認者・確認日・証拠写真等の必須記録や承認ワークフローは実装されていません。
- 候補地点のチーム内同時編集、アカウント管理、サーバーへの自動保存、データの自動統合には対応していません。
- 背景地図・Googleマップ／ストリートビューへの接続は、通信環境と各サービスの提供状況に左右されます。

## 9. よくある質問

**Q. 地図上の施設点は、そのまま車いす用駐車スペースですか？**  
A. いいえ。施設点は指定座標です。実際の駐車区画は、候補地点として別に記録して確認します。

**Q. 車いす等／プラスワンの「記載なし」は0区画ですか？**  
A. いいえ。元データに数値の記載がない状態です。

**Q. 候補を追加したらチーム全員に表示されますか？**  
A. いいえ。各ブラウザに保存されます。共有にはテキストまたはJSONの受け渡しが必要です。

**Q. JSONを読み込むと今の候補は残りますか？**  
A. 読み込んだ内容で置き換わります。先にJSONを書き出してください。

**Q. 候補のポップアップがオレンジやブルーになるのはなぜですか？**  
A. 最初から収録された施設点と、利用者が保存した調査候補を区別するためです。オレンジは調査候補、ブルーは「現地確認済み」として登録した候補です。

**Q. 地図がアニメーションせずに拡大・縮小します。**  
A. OS／ブラウザで動きを抑える設定が有効な場合は、アニメーションを省略します。地図操作自体の機能は変わりません。

**Q. 地図の背景が表示されません。**  
A. 通信環境と国土地理院タイルへの接続状況を確認してください。HTML内の施設・道路データが消えたという意味ではありません。
